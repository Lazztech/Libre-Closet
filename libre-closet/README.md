# Libre Closet Home Assistant Add-on

Self-hosted wardrobe organizer for Home Assistant.

## Installation

1. Add this repository to Home Assistant:

   `Settings → Add-ons → Add-on Store → ⋮ → Repositories → Add https://github.com/Lazztech/Libre-Closet#ha-addon`

2. Find **Libre Closet** in the add-on store and install it.
3. Start the add-on.
4. Click the **Libre Closet** item in the sidebar to open the UI.

## Configuration

The add-on runs with sensible defaults:

- Data is persisted to `/data`.
- Authentication is disabled by default (open personal use).
- PWA features are disabled because the app runs through Home Assistant ingress.

You can override these from the add-on configuration page if needed.
